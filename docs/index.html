三步开始使用

无需后端，加载到 Chrome / Edge 即可运行

下载源码

获取 ImageGrab 插件目录，确认包含 manifest.json、content.js、background.js 与 gallery 页面。

加载扩展

打开 chrome://extensions，开启开发者模式，点击“加载已解压的扩展程序”，选择插件目录。

提取图片

打开淘宝、京东或拼多多商品详情页，点右下角“获取图片”，在新页面勾选并下载。
